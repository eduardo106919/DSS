# Templates para Especificação de Casos de Uso

Este repositório disponibiliza templates para a documentação de **Especificações de Casos de Uso**, desenvolvidos especificamente para as necessidades da unidade curricular de **Desenvolvimento de Sistemas de Software (DSS)** na Universidade do Minho.

Estão disponíveis versões tanto em **LaTeX** quanto em **Typst**, garantindo um layout profissional com suporte nativo para fluxos normais, alternativos e de exceção.

## Visão Geral dos Templates

### Especificação Completa (`full_uc_spec`)

Ideal para operações complexas que exigem detalhamento de lógica de negócio, definições de API e mapeamento de subsistemas. Inclui tabelas multi-coluna e numeração automática de passos.

- **Destaques:** Tabelas horizontais (landscape) para maior legibilidade e cabeçalhos coloridos por tipo de fluxo.
- **Previews:** [LaTeX PDF](latex/full_uc_spec.pdf) | [Typst PDF](typst/full_uc_spec.pdf)

### Especificação Simples (`simple_uc_spec`)

Uma versão compacta focada na descrição central e nos fluxos. Perfeita para documentação rápida ou interações de sistema menos granulares.

- **Destaques:** Layout limpo e direto, priorizando a descrição do cenário.
- **Previews:** [LaTeX PDF](latex/simple_uc_spec.pdf) | [Typst PDF](typst/simple_uc_spec.pdf)
